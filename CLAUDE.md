# MOHs

Harness em TypeScript/Node para conduzir agentes de código. A fonte da verdade do desenho é `docs/ARCHITECTURE.md`.

- Código em inglês; textos para o usuário e comentários (só onde ajudam) em português.
- `npm test`, `npm run typecheck` e `npx prettier --check .` antes de commitar.
- Validações do harness seguem `docs/VALIDATION.md` (`npm run validate`).
